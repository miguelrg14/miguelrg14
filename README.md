## About me

I graduated in **Design and Development of Video Games and Virtual Environments** (UDIT Madrid, 2025), after a
**Computer Science & Video Game Engineering** degree and an HND in Game Development at ESNE Asturias.
I did my internship there as a Unity developer, building a zombie horde shooter on my own from start to finish.

I enjoy gameplay systems, game AI and the technical side of graphics. My projects have been shown at
**CometCon Gijón**, **PS Talents** and **Match in Games**.

- 🎮 Most of my games **can be played in the browser** — links below
- 🧪 My main repos have **tests, CI and automatic builds** (GitHub Actions, GameCI): game rules live in engine-free C# assemblies that run with `dotnet test`
- 🔧 Currently building **Genesis Engine**, a C++20 game engine, to learn engine architecture
- 🌍 Spanish & Galician (native), English (B2, working towards C1)
